# Connext

ServiceNow-inspired student case-management demo for IGDTUW × ServiceNow, built with plain HTML, CSS and JavaScript.

No installation or API keys are needed. From this workspace:

```sh
npm run dev
```

Open **http://127.0.0.1:4173**. Alternatively, open `connext-app/dist/index.html` directly in your browser.

Run `npm test` for the workflow and rendering checks.

See [the application README](connext-app/README.md) for features, a presentation walkthrough, architecture and demo limitations.

All data is fictional. Authentication, AI and the backend are simulated; browser storage preserves demo changes locally.
